# Stories index

> **Retired as a hand-maintained file, per `ADR-004`.** This table used to be hand-edited
> here and collided at merge time when two initiatives added stories in parallel — the exact
> incident `ADR-004` exists to prevent. The ID/title/phase/requirements/status table is fully
> derivable from each story file's own frontmatter (`templates/story.md`'s fields) and is
> computed live by `/delivery:status` — nothing to hand-maintain, nothing left to collide.
> Run `/delivery:status` for the current table.
>
> Authored narrative (build order, cross-story reconciliation notes) that isn't derivable
> data lives per-initiative instead of shared here — see
> `../initiatives/harden/notes.md` and `../initiatives/chief-of-staff/notes.md`.
